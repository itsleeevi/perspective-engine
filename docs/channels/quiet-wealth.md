# Quiet Wealth

Internal mode: `wealth_pov` (aliases: `quiet_wealth`, `wpov`, `pov_wealth`, `longform_wealth_pov`).
Playbook: `docs/wealth-pov.md`. Config: `WEALTH_POV`.
Prompts: `channel/wealth_prompts.py` (`MASTER` is the v5 long-form wealth POV prompt). Index after ship: `docs/wealth/`.

This is **not** a documentary. Second person. Fictional illustrative stories by default.

## Channel promise

Let the viewer live through ordinary money decisions and see how those choices change a life. Finish with calm and agency, not a guaranteed balance.

## Target audience

Adults who feel the social pressure to look successful and want a story about quiet choices, time, and enough.

## Runtime and narration length

| | Value |
|---|---|
| Runtime | **~30 minutes** (28–32; 1680–1920s, target 1800) |
| Script | **4,500–4,800** words |
| Spoken pace | 150–160 wpm |
| Voice | imported audio; Kokoro `am_liam` 1.15 on recuts |
| Chapters | 6 named levels |
| Shots | new still every 8–9 seconds |

## Narration personality

Calm, warm, observant. Second person. Simple words. One idea per sentence.

## Story architecture

```text
familiar opening → first quiet choice → habit meets life → tempting upgrade
→ setback → new option with a relationship cost → what money did not settle
→ return to the opening object
```

## Research priorities

Default fiction: continuity ledger, not Wikipedia. Source only real financial / legal / tax / statistical claims (Investor.gov for index-fund explanations). Never invent private finances of a real named person.

## Title interpretation

`POV: You …` immersive titles. A Think / Money / Takeover title here is wrong — raise and point to the matching `--channel`.

## Visual identity

`WEALTH_POV_VISUAL_STYLE`: detailed colored 2D narrative cartoons. Not stick-figure doodle.

## Thumbnail strategy

Large protagonist plus one contrast. 0–4 optional words. Default overlay `THE QUIET CHOICE`.
